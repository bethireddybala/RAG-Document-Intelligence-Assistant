# 🔍 RAG Document Intelligence Assistant

A beginner-friendly **Streamlit** application that demonstrates **Retrieval Augmented Generation (RAG)** — upload your own documents and ask questions about their content. Answers are generated by **Google Gemini** and are grounded exclusively in the uploaded documents.

---

## 📖 What is RAG?

**Retrieval Augmented Generation (RAG)** is a technique that improves large language model (LLM) answers by:

1. **Retrieving** the most relevant passages from a knowledge base (your documents).
2. **Augmenting** the LLM prompt with those passages as context.
3. **Generating** an answer that is grounded in the provided context rather than the LLM's parametric memory.

This prevents hallucinations and allows the LLM to answer questions about private or domain-specific documents it was never trained on.

```
│                                                         │
│  ❓ User Question                                       │
│       │                                                 │
│       ▼                                                 │
│  🔢 Question Embedding                                  │
│       │                                                 │
│       ▼                                                 │
│  🔍 Cosine Similarity Search → Top-K Chunks            │
│       │                                                 │
│       ▼                                                 │
│  📝 Augmented Prompt  (question + context + rules)     │
│       │                                                 │
│       ▼                                                 │
│  🤖 Gemini LLM                                         │
│       │                                                 │
│       ▼                                                 │
│  ✅ Grounded Answer + 📎 Source Citations              │
└─────────────────────────────────────────────────────────┘
```

| # | RAG Concept | Where in Code |
|---|-------------|---------------|
| 1 | **Document Ingestion** | `utils/document_processor.py` → `process_document()` |

| 6 | **Retrieval** | `utils/vector_store.py` → `VectorStore.retrieve()` |

## 🚀 Installation

### Prerequisites
- Python 3.10 or higher
- A free [Gemini API key](https://aistudio.google.com/app/apikey)

### Steps

```bash
# 1. Clone or download this repository
git clone https://github.com/your-username/rag-document-assistant.git
cd rag-document-assistant

# 2. Create and activate a virtual environment (recommended)
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt
```

## 🔑 Configuring the Gemini API Key

**Option A — Environment variable (recommended for local dev)**

```bash
# Windows PowerShell
$env:GEMINI_API_KEY = "your_key_here"
streamlit run app.py

# macOS / Linux
export GEMINI_API_KEY="your_key_here"
streamlit run app.py
```

**Option B — `.streamlit/secrets.toml` (recommended for Streamlit Cloud)**

```toml
# .streamlit/secrets.toml  (do NOT commit this file)
GEMINI_API_KEY = "your_key_here"
```

**Option C — Sidebar input**

Enter the key directly in the sidebar text field each time you run the app.

> ⚠️ **Never hard-code your API key in source files or commit it to version control.**

## ☁️ Deploying on Streamlit Community Cloud

1. Push this repository to GitHub.
2. Go to [share.streamlit.io](https://share.streamlit.io/) and sign in.
3. Click **New app** → select your repository → set `app.py` as the main file.
4. Open **Advanced settings → Secrets** and add:
   ```
   GEMINI_API_KEY = "your_key_here"
   ```
5. Click **Deploy**.

## ⚙️ Configuration Reference

| Setting | Default | Description |
|---------|---------|-------------|
| Chunk size | 800 chars | Max characters per chunk (edit in `document_processor.py`) |
| Chunk overlap | 150 chars | Overlap between consecutive chunks |
| Embedding model | `all-MiniLM-L6-v2` | Change in `embeddings.py` |
| Top-K | 5 | Adjustable in the sidebar slider |
| Gemini model | `gemini-1.5-flash` | Change `DEFAULT_GEMINI_MODEL` in `rag_pipeline.py` |

## ⚠️ Limitations

- Documents are processed and stored **in memory only** — they are lost when the Streamlit session ends.
- Very large documents (100+ pages) may be slow to process.
- Only **PDF** and **TXT** formats are supported (no DOCX, HTML, etc.).
- The embedding model runs on CPU; first load takes a few seconds.
- Answer quality depends on chunk size, Top-K setting, and document clarity.
